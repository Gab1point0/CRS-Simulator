# 🚔 CRS Simulator

Petit jeu parodique jouable dans le navigateur : vous incarnez un CRS en pleine manif.

- ✊ Manifestant : **+10** · 🎒 Lycéen : **+15**
- 🎤 Journaliste CNews : **−20** · 🕶️ Policier en civil : **−25** · 👵 Vieille dame : **−30**

60 secondes, ça accélère au fil du temps, record sauvegardé dans le navigateur.

## Jouer

En ligne via GitHub Pages : https://gab1point0.github.io/CRS-Simulator/

En local : ouvrez simplement `index.html` dans un navigateur.

*Jeu humoristique, toute ressemblance avec des faits réels serait purement fortuite.*
